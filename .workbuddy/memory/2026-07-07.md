## 配色可读性修复 + 双主题 + 列表页标杆化（续）

- **根因**：上一个开发者把整站用写死的 indigo(靛蓝 `#6366f1`/`#4338ca` 蓝字)+纯白(`#fff`)做了一套浅色主题，每个页面 `<style scoped>` 都是硬编码。全局暗色只覆盖了 Element Plus 基础变量，覆盖不了页面级硬编码 → 暗色下「黑底+蓝字+白斑」(用户报的看不清)。
- **方案**：建立双主题令牌系统（`frontend/src/styles/design-tokens.css` 与 `element-overrides.css`）：
  - `:root` = 亮色（白底+emerald）；`html.dark` = 暗色。所有页面只引用 `--sb-*` 令牌，切 `html.dark` 即整体换肤。
  - 新增令牌：`--sb-accent-bg/-2`、`--sb-accent-border`、`--sb-accent-soft/-soft-2`、`--sb-success/-bg`、`--sb-danger/-bg`、`--sb-warning/-bg` 等，用于替代原 indigo 点缀。
- **已改造页面**（indigo/白底 → 令牌）：`ChainList.vue`、`ExecuteList.vue`（手动重写 `<style scoped>`）、`ChainEdit.vue`（用脚本 `/tmp/fix_chainedit.py` 全量替换 ~870 行样式，幂等可重跑）。`Login.vue` 本就是令牌化，无需改。
- **亮/暗切换开关**：`App.vue` 侧边栏底部加 Sunny/Moon 按钮，`toggleTheme()` 切 `html.dark` 并写 `localStorage('theme')`；`index.html` 加首屏前内联脚本按 localStorage 应用主题（默认暗色，防闪烁）。
- **验证**：`npm run build` 通过（0 报错）。用户需在本机 `npm run dev` 查看（沙箱不可达）。
- **重要发现**：Monaco、LogicFlow 在 `package.json` 声明了依赖，但前端 `src` 中**无任何实例化代码**——「代码编辑器」实为 `el-input textarea`，编排画布是自定义 DOM。即这两项目前「没接入」，不是「接入了但没换肤」。待用户确认是否要真正集成。
- 仍可深化的其他列表/表单页（`AccountList`、`UserList`、`DictCategory` 等）仍残留原 indigo 硬编码主题，需同样令牌化（用户未要求，可后续）。
