## 生产部署文档

- 编写了 `doc/260709-生产部署/部署文档.txt` 纯文本部署文档
- 项目无 Agent 概念，仅一个 Spring Boot jar + 前端静态文件
- Token 是登录时自动生成的 JWT，启动不需要任何 token
- 部署只需 5 步: 数据库 → 改配置 → 启动后端 → 前端挂 Nginx → 访问
- 需改配置: 数据库连接、JWT密钥(32+字符)、AES密钥(16字节)、AI地址、日志级别

## 前端 Nginx 打包 (ARM64 Linux)

- 在 `frontend/nginx/` 下载并配置了开箱即用的 Nginx
- 二进制来源: jirutka/nginx-binaries (静态链接，任意 ARM64 Linux 可运行)
- 已下载: `sbin/nginx` = nginx 1.26.2 aarch64 静态二进制 (file 验证: ELF 64-bit ARM aarch64, statically linked)
- `conf/nginx.conf` 全注释，前端 ../dist + /api 代理 + /ws WebSocket
- `conf/mime.types` 从 nginx 官方源码下载
- 脚本: start.sh/stop.sh/restart.sh (用 -p prefix 自动定位目录，相对路径)
- README.txt 使用说明
- 仅 2 处需改: listen 端口、proxy_pass 后端地址
- 注意: 无法在 Windows 上运行 ARM64 二进制验证，配置为标准写法需到 Linux 上 chmod +x 后测试
