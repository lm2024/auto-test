# 稳定性能力迭代 - 实施计划

## 需求确认摘要

| # | 需求 | 关键决策 |
|---|------|----------|
| 1 | 插件模块 | 底部菜单，crx 下载 + 更新日志 + 浏览器说明 |
| 2 | 定时任务 | Cron + 简单间隔，支持单链路/按分类批量执行 |
| 3 | 树形分类 | 替换现有两层分类，最多 4 级，拖拽 + CRUD + 搜索 |
| 4 | 分类公共组件 | Vue 组件，链路管理/执行记录共用分类筛选 |
| 5 | 链路操作列 | 三个点 → 下拉菜单 |
| 6 | 租户 | 逻辑隔离，tenant_id 字段 |
| 7 | SSO 登录 | OAuth 2.0/OIDC，与本地登录并存 |
| 8 | 用户管理 | 基础 CRUD（用户名、密码、角色） |

#### 1.1 数据库变更 - 新增表

**文件**: `docker/init.sql`, `backend/src/main/resources/application.yml`

新增以下表（追加到 init.sql 末尾）：

```sql
-- 租户表
CREATE TABLE sys_tenant (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  tenant_code VARCHAR(64) NOT NULL UNIQUE,
  tenant_name VARCHAR(128) NOT NULL,
  status INT DEFAULT 1,
  create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
  update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

-- 用户表（替换或新增，当前无用户表）
CREATE TABLE sys_user (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  username VARCHAR(64) NOT NULL UNIQUE,
  password VARCHAR(256) NOT NULL,
  display_name VARCHAR(128),
  role VARCHAR(32) DEFAULT 'USER',
  tenant_id BIGINT,
  status INT DEFAULT 1,
  last_login_time DATETIME,
  create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
  update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

-- SSO 映射表
CREATE TABLE sys_user_sso (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  user_id BIGINT NOT NULL,
  sso_provider VARCHAR(64),
  sso_subject VARCHAR(128) NOT NULL,
  UNIQUE KEY uk_sso (sso_provider, sso_subject)
);

-- 树形分类表（替换 dict_category）
CREATE TABLE sys_category (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  parent_id BIGINT DEFAULT 0,
  category_name VARCHAR(128) NOT NULL,
  sort_order INT DEFAULT 0,
  icon VARCHAR(64),
  tenant_id BIGINT,
  status INT DEFAULT 1,
  create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
  update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  KEY idx_parent (parent_id),
  KEY idx_tenant (tenant_id)
);

-- 定时任务表
CREATE TABLE sys_scheduled_task (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  task_name VARCHAR(128) NOT NULL,
  task_type VARCHAR(32) NOT NULL COMMENT 'SINGLE/CATEGORY',
  chain_code VARCHAR(64),
  category_id BIGINT,
  cron_expression VARCHAR(64),
  interval_minutes INT,
  enabled INT DEFAULT 1,
  last_run_time DATETIME,
  next_run_time DATETIME,
  tenant_id BIGINT,
  create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
  update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

-- 定时任务执行日志
CREATE TABLE sys_task_execute_log (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  task_id BIGINT NOT NULL,
  execution_ids TEXT,
  status VARCHAR(16),
  trigger_type VARCHAR(32) COMMENT 'SCHEDULED/MANUAL',
  start_time DATETIME,
  end_time DATETIME,
  error_message TEXT,
  create_time DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### 第二期：SSO 对接 + 登录页

#### 2.1 后端 - OAuth2/OIDC SSO

**新增文件**:
- `controller/SsoController.java` → `/api/sso/*`
- `service/SsoService.java` + `impl/SsoServiceImpl.java`
- `config/OAuth2Config.java` - OAuth2 客户端配置

**SSO 流程**:
1. `GET /api/sso/login` → 重定向到公司 OAuth2 授权页
2. `GET /api/sso/callback?code=xxx` → 用 code 换 token → 获取用户信息 → 查找/创建本地用户 → 签发 JWT
3. `GET /api/sso/providers` → 返回可用的 SSO 提供商列表

**修改文件**:
- `application.yml` → 新增 OAuth2 配置（clientId, clientSecret, authorizeUrl, tokenUrl, userInfoUrl）

#### 2.2 前端 - 登录页

**新增文件**:

**修改文件**:
- `frontend/src/router/index.js` → 新增 `/login` 路由，添加路由守卫
- `frontend/src/App.vue` → 未登录时跳转登录页，登录后显示用户信息

**登录页设计**:

### 第三期：树形分类管理

#### 3.1 后端 - 树形分类 API

**修改文件**:
- `controller/DictCategoryController.java` → 保留兼容，新增树形接口
- `service/DictCategoryService.java` + `impl/DictCategoryServiceImpl.java` → 新增树形方法

**新增接口**:
- `GET /api/category/tree` → 返回完整分类树（递归结构）
- `POST /api/category/create` → 创建分类（支持 parentId）
- `PUT /api/category/update?id=` → 编辑分类
- `DELETE /api/category/delete?id=` → 删除分类（含子分类处理）
- `PUT /api/category/sort` → 批量更新排序（拖拽用）
- `GET /api/category/search?keyword=` → 搜索分类
- `POST /api/category/execute?id=` → 执行该分类下所有链路

**数据结构**:
```json
{
  "id": 1,
  "categoryName": "用户管理",
  "parentId": 0,
  "children": [
    {
      "id": 2,
      "categoryName": "登录模块",
      "parentId": 1,
      "children": [
        { "id": 5, "categoryName": "SSO登录", "parentId": 2, "children": [] }
      ]
    }
  ]
}
```

#### 3.2 前端 - 树形分类公共组件

**新增文件**:
- `frontend/src/components/CategoryTree.vue` - 树形分类公共组件

**组件功能**:
- 使用 `el-tree` 渲染分类树
- 支持拖拽排序（`draggable` 属性）
- 右键菜单：新增子分类、编辑、删除
- 顶部搜索框：快速过滤节点
- 选中节点后 emit 事件，父组件可执行链路测试
- 可配置模式：`mode="select"`（选择模式，用于筛选）/ `mode="manage"`（管理模式，用于 CRUD）

**Props**:
- `mode`: 'select' | 'manage'
- `modelValue`: 当前选中分类 ID
- `multiple`: 是否多选

**Events**:
- `update:modelValue`: 选中变化
- `execute`: 执行分类下链路
- `refresh`: 树数据变化

#### 4.2 定时任务

**后端**:
- `controller/ScheduledTaskController.java` → `/api/task/*`
- `service/ScheduledTaskService.java` + `impl/ScheduledTaskServiceImpl.java`
- `scheduler/TaskScheduler.java` - 定时任务调度器（基于 Spring `@Scheduled` 或自建线程池）

**接口**:
- `POST /api/task/create` - 创建定时任务
- `PUT /api/task/update?id=` - 编辑
- `DELETE /api/task/delete?id=` - 删除
- `GET /api/task/list` - 任务列表
- `POST /api/task/trigger?id=` - 手动触发一次
- `PUT /api/task/toggle?id=` - 启用/禁用

**调度器实现**:
- 使用 `ScheduledExecutorService` 管理任务
- 支持 Cron 表达式和固定间隔两种模式
- 任务触发时：查询分类下所有链路 → 逐条执行 → 记录日志
- 应用启动时加载所有 enabled 任务

**前端**:
- `frontend/src/views/ScheduledTask.vue` - 定时任务管理页

**页面功能**:
- 任务列表表格（名称、类型、Cron/间隔、上次执行、状态）
- 新增/编辑对话框：任务名、类型（单链路/分类）、Cron 表达式或间隔配置、链路选择器或分类选择器
- 手动触发按钮

## 验证方案

1. **数据库**: 重启 MySQL 容器（`docker-compose down -v && up -d`），验证所有表和索引创建成功
2. **后端编译**: `JAVA_HOME=corretto-1.8 mvn compile` 通过
3. **用户管理**: curl 测试 CRUD + 登录获取 JWT
4. **SSO**: 本地启动后，访问 `/api/sso/login` 验证重定向
5. **分类树**: curl `/api/category/tree` 验证递归结构
6. **前端**: `npm run dev` 启动，逐页验证
7. **链路操作列**: 验证下拉菜单显示和功能
8. **分类筛选**: 链路列表/执行记录按分类筛选正确
9. **定时任务**: 创建任务 → 验证调度触发 → 查看执行日志
10. **插件下载页**: 页面显示正常，下载按钮可用
