# 详细设计文档 v1.0 - 前端可视化平台模块

## 1. 模块概述

前端可视化平台模块基于 Vue 3 + Vite + Element Plus + LogicFlow技术栈，提供可视化流程编排、执行状态展示、节点详情编辑、日志查询、AI功能交互等核心能力。采用左-中-右三栏标准布局，支持拖拽式画布完成流程调整，节点参数支持JSON格式化编辑、一键复制，普通测试人员无需编码即可上手。

## 6. AI功能交互设计

### 6.1 全链路测试数据生成

```
交互流程:

1. 用户在编排页工具栏点击「AI生成测试数据」
   ↓
2. 前端校验: 链路是否存在节点配置?
   → 无: 提示「请先配置链路节点」
   → 有: 弹出配置弹窗
   ↓
3. 配置弹窗:
   ┌─────────────────────────────────┐
   │ ID生成模式: [自增模式 ▼]        │
   │ 步长: [1]  (1-20)              │
   │ 起始ID: [____] (自定义模式)     │
   │                                 │
   │ [取消] [确认生成]               │
   └─────────────────────────────────┘
   ↓
4. 确认后按钮置灰, 显示加载动画
   ↓
5. 调用后端AI接口, 等待响应
   ↓
6. 生成完成后, 自动回填所有节点的请求头、请求体
   ↓
7. 弹出成功提示: 「测试数据生成成功, 请确认后再保存」
   ↓
8. 用户确认: 保存到数据库 或 仅前端临时回填
```

### 6.2 失败原因分析

```
交互流程:

1. 用户在节点详情弹窗中点击「AI分析失败原因」
   ↓
2. 按钮置灰, 显示加载动画
   ↓
3. 调用后端AI接口, 传入:
   - 完整请求信息 (URL/方法/请求头/请求体)
   - 响应信息 (响应码/响应体)
   - 错误堆栈信息
   ↓
4. 接收AI返回的三字段结果:
   - 根因定位
   - 排查步骤
   - 修复方案
   ↓
5. 以结构化卡片展示结果, 支持复制内容
```

## 7. 关键技术点

### 7.1 LogicFlow 画布配置

```javascript
const lf = new LogicFlow({
  container: canvasContainer,
  grid: true,                // 网格对齐
  background: '#f5f5f5',     // 背景色
  keyboard: {                  // 快捷键
    global: {
      undo: 'mod+z',
      redo: 'mod+y',
      delete: 'Backspace'
    }
  },
  plugins: [miniMap]          // 小地图插件
});

// 自定义节点样式
lf.register({
  type: 'httpNode',
  view: HttpNodeView,          // 自定义节点视图
  edgesType: 'polyline'        // 连线类型
});
```

### 7.2 JSON编辑器集成

使用 Monaco Editor 实现JSON格式化编辑:

```javascript
import * as monaco from 'monaco-editor';

const editor = monaco.editor.create(container, {
  value: jsonData,
  language: 'json',
  theme: 'vs-dark',
  minimap: { enabled: false },
  scrollBeyondLastLine: false,
  automaticLayout: true
});

// 格式化
editor.getAction('editor.action.formatDocument').run();

// 一键复制
navigator.clipboard.writeText(editor.getValue());
```

### 7.3 WebSocket集成

```javascript
// 执行页面建立WebSocket连接
const ws = new WebSocket(
  `ws://${location.host}/ws/execute/${executionId}`
);

ws.onmessage = (event) => {
  const message = JSON.parse(event.data);
  if (message.type === 'NODE_STATUS') {
    updateNodeStatus(message);    // 更新节点状态
  } else if (message.type === 'CHAIN_STATUS') {
    updateChainStatus(message);    // 更新链路状态
  }
};

ws.onclose = () => {
  // 断线重连逻辑
  reconnect(executionId);
};
```

## 8. 异常处理

| 异常场景 | 处理方式 | 前端提示 |
|----------|----------|----------|
| 网络请求失败 | 重试1次, 仍失败提示用户 | 「网络异常, 请重试」 |
| 画布节点过多(>100) | 限制节点数, 提示优化 | 「节点数超过100, 请优化」 |
| JSON格式错误 | 编辑器高亮错误位置 | 编辑器内红色波浪线 |
| AI调用超时(120秒) | 提示超时, 可重试 | 「AI调用超时, 请稍后重试」 |
| WebSocket断线 | 自动重连, 最多5次 | 重连中提示「连接中...」 |
| 执行链路无节点 | 拒绝执行 | 「请先添加节点再执行」 |
| 页面刷新 | 保留执行状态, 重连WebSocket | 重新拉取执行状态 |
