**ActionExecutor 内部实现（关键逻辑）：**

```java
public StepResult execute(BrowserAction action, Page page) {
    StepResult result = new StepResult();
    result.setActionType(action.getActionType());
    result.setStepIndex(action.getStepIndex());
    long startTime = System.currentTimeMillis();
    
    try {
        // 等待延时
        if (action.getWaitDelayMs() > 0) {
            Thread.sleep(action.getWaitDelayMs());
        }
        
        switch (action.getActionType()) {
            case "navigate":
                page.navigate(action.getTargetUrl());
                break;
            case "click":
                page.locator(action.getTargetSelector()).click();
                break;
            case "input":
                page.locator(action.getTargetSelector()).fill(action.getValue());
                break;
            case "select":
                page.locator(action.getTargetSelector()).selectOption(action.getValue());
                break;
            case "check":
                page.locator(action.getTargetSelector()).setChecked(
                    Boolean.parseBoolean(action.getValue()));
                break;
            case "wait":
                Thread.sleep(action.getWaitDelayMs() > 0 ? 
                    action.getWaitDelayMs() : 1000);
                break;
            case "screenshot":
                // 只截图，不当作步骤（由框架自动截图）
                break;
            case "assert":
                result.setAssertResult(executeAssert(action, page));
                break;
            case "evaluate":
                Object evalResult = page.evaluate(action.getValue());
                result.setEvalResult(evalResult);
                break;
        }
        
        result.setStatus("SUCCESS");
    } catch (Exception e) {
        result.setStatus("FAILED");
        result.setErrorMessage(e.getMessage());
        if (action.isContinueOnFail()) {
            // 标记失败但继续
        }
    }
    
    result.setCostMs(System.currentTimeMillis() - startTime);
    result.setPageUrl(page.url());
    result.setPageTitle(page.title());
    return result;
}
```

```java
public List<BrowserAction> generateScript(String naturalLang, ScriptContext context) {
    // 1. 构建 system prompt，定义输出格式
    String systemPrompt = buildScriptGenerationPrompt(context);
    
    // 2. 调用 AI 模型（复用现有 OpenAiChatModel）
```

**SystemPrompt 示例：**

```
你是一个浏览器自动化测试脚本生成专家。
用户会用自然语言描述一个测试场景，你需要将其转换为结构化的操作步骤。

可用的操作类型：
- navigate: 导航到URL，参数: targetUrl
- click: 点击元素，参数: targetSelector
- input: 输入文本，参数: targetSelector, value
- select: 选择下拉项，参数: targetSelector, value
- check: 勾选/取消复选框，参数: targetSelector, value(true/false)
- wait: 等待，参数: waitDelayMs
- screenshot: 截图（用于验证）
- assert: 断言，参数: assertType(visible/notVisible/text/exists/notExists/urlContains), assertValue
- evaluate: 执行JS，参数: value

输出格式必须是严格的JSON数组，不要包含任何其他文字：
[
  {
    "actionType": "navigate",
    "targetUrl": "https://...",
    "description": "打开登录页面"
  },
  ...
]

要求：
1. 每个步骤必须有description字段
2. 关键操作后添加screenshot步骤用于验证
3. 登录操作后添加适当等待
4. 使用通用的、语义化的CSS选择器
```

#### 3.1.3 BrowserTaskScheduler

```java
/**
 * 浏览器任务定时调度器
 * 基于 Spring TaskScheduler，动态注册/取消定时任务
 */
@Service
public class BrowserTaskScheduler {
    
    @Autowired
    private ThreadPoolExecutor executeThreadPool;  // 复用现有线程池
    
    @Autowired
    private BrowserTaskService browserTaskService;
    
    // 存储已注册的任务: taskCode → ScheduledFuture
    private final ConcurrentHashMap<String, ScheduledFuture<?>> scheduledTasks = new ConcurrentHashMap<>();
    
    /**
     * 注册定时任务
     */
    public void scheduleTask(String taskCode, String cronExpression) {
        // 解析 cron
        CronTrigger trigger = new CronTrigger(cronExpression);
        // 在线程池中注册
        ScheduledFuture<?> future = Executors.newSingleThreadScheduledExecutor()
            .schedule(() -> {
                browserTaskService.executeTask(taskCode, "CRON");
            }, trigger);
        scheduledTasks.put(taskCode, future);
    }
    
    /**
     * 取消定时任务
     */
    public void cancelTask(String taskCode) {
        ScheduledFuture<?> future = scheduledTasks.remove(taskCode);
        if (future != null) {
            future.cancel(false);
        }
    }
    
    /**
     * 重启所有已启用的定时任务（应用启动时调用）
     */
    @PostConstruct
    public void reloadAllSchedules() {
        List<BrowserSchedule> schedules = browserScheduleMapper.selectEnabled();
        for (BrowserSchedule schedule : schedules) {
            scheduleTask(schedule.getTaskCode(), schedule.getCronExpression());
        }
    }
}
```

```java
private BrowserAction convertMacroToBrowser(MacroAction macro) {
    BrowserAction action = new BrowserAction();
    action.setActionType(macro.getType());  // 类型名称兼容
    if (macro.getElement() != null) {
        action.setTargetSelector(macro.getElement().getSelector());
    }
    if (macro.getValue() != null) {
        action.setValue(macro.getValue());
    }
    if (macro.getUrl() != null) {
        // navigate 用 url，其他用 pageUrl
        if ("navigate".equals(macro.getType())) {
            action.setTargetUrl(macro.getUrl());
        }
    }
    action.setWaitDelayMs(500);
    action.setTimeoutMs(10000);
    action.setDescription(macro.getType() + " " + 
        (macro.getElement() != null ? macro.getElement().getSelector() : ""));
    return action;
}
```

### 4.5 AI 脚本生成面板交互流程

```
用户打开 TaskEditor → 点击 "AI生成" 面板

                  ↓
输入需求文本（如 "打开百度，搜索天气预报，截图搜索结果"）

                  ↓
点击 "生成脚本" → 调用 POST /api/browser/ai/generate

                  ↓
AI 返回操作脚本 → 在步骤列表中显示（带高亮动画标记"AI生成"）

                  ↓
用户可以：
  - 直接点击"运行"体验效果
  - 拖拽调整步骤顺序
  - 修改选择器/值
  - 添加/删除步骤
  - 点击"重新生成"让 AI 优化

                  ↓
满意后点击"保存"
```

## 7. 异常处理与容错

| 场景 | 处理方式 |
|------|---------|
| AI 模型不可用 | 降级提示，用户可手动编辑步骤 |
| 浏览器启动失败 | 重试 3 次，仍失败则记录错误并终止 |
| 元素找不到 | 等待 timeout 后失败，记录截图 + 页面内容 |
| 网络断开 | 尝试重连页面，超时则终止 |
| 定时任务执行中手动运行 | 另起会话执行，不影响定时任务 |
| 并发执行 | 每个执行任务使用独立浏览器会话 |

## 8. 安全考虑

1. **浏览器隔离**：每次执行使用独立的浏览器上下文（BrowserContext），不共享 cookies/storage
2. **截图清理**：定期清理过期截图文件
3. **超时控制**：所有操作都有默认超时时间，防止浏览器进程长期驻留
4. **账号安全**：涉及登录的操作，密码变量化存储，复用现有 AES 加密机制
