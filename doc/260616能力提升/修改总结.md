## 核心改动说明

### ExecuteServiceImpl 账号集成

执行链路前自动绑定测试账号的完整流程：

1. 读取chain绑定的accountCode
2. 调用accountService.acquireAccount()获取并锁定账号（30分钟）
3. 根据authType调用对应的认证接口获取token：
   - SSO：POST tokenUrl，form-urlencoded格式
   - PASSWORD：POST loginUrl，JSON格式
   - TOKEN：直接返回配置的token
4. 将token存入ExecutionContext变量`__ACCOUNT_TOKEN__`
5. 执行节点时自动注入Authorization头
6. finally块中释放账号锁

### ChainServiceImpl.pluginAppendChain() 透传

追加节点时透传Phase 2字段：bizOperTraceId、triggerEvent、targetDom、pageUrl、windowId、isIgnored。

### NodeConfigServiceImpl.buildNodeVO() 补全

所有通过NodeConfigService返回的节点信息现在包含Phase 2字段。

## 核心改动说明

### SSO多轮跳转捕获（background.js）

- CDP Network.requestWillBeSent事件中检测重定向链（301/302）
- 记录redirectLocation和redirectFrom字段
- 重定向链中的所有请求携带bizOperTraceId

### Token自动提取（background.js）

三层提取机制：

1. **响应头提取**：Set-Cookie中的token/session/auth/jwt/access/sid/jsessionid
2. **请求头提取**：Authorization Bearer token
3. **响应体提取**：JSON中的token/access_token/refresh_token/id_token字段，自动解析JWT exp过期时间
4. **URL参数提取**：access_token、code、ticket

提取的token存入capturedTokens对象，在设置面板的SSO认证信息区域展示。

### 加密请求解密（inject.js + sandbox.html）

- inject.js监听AUTOTEST_ENCRYPT_CONFIG消息获取解密配置
- save()函数中尝试用用户配置的解密函数解密请求体和响应体
- 解密后的明文存入decryptedBody/decryptedResponse字段
- 通过sandbox.html的iframe sandbox执行解密函数，避免安全风险

### 设置面板新增（sidepanel.html/js）

- 加密请求处理区域：启用/禁用、请求体解密函数、响应体解密函数、加密算法选择
- SSO认证信息区域：显示录制期间自动提取的认证信息，支持一键清除

### 后端AuthController

- POST /api/auth/token：根据账号编码获取token，支持SSO/PASSWORD/TOKEN三种类型
- POST /api/auth/refresh：刷新token
- GET /api/auth/validate：验证JWT token有效性（解析exp字段）

## 核心改动说明

### 插件分组推送（sidepanel.js doPush()）

推送逻辑改造：

1. 按bizOperTraceId将勾选的API分组
2. 未分组的API（无TraceId）单独作为一组
3. 单组或无分组时：按原有逻辑推送为一条链路
4. 多组时：每组独立推送为一条链路，命名规则：`{名称}_{触发事件}_{TraceId片段}`
5. 推送完成后显示成功/失败统计，支持跳转到平台查看

每条接口携带的字段：bizOperTraceId、triggerEvent、targetDom、pageUrl、windowId、isIgnored

### ChainList.vue 分类筛选

- 筛选栏：系统分类下拉、功能分类下拉、优先级下拉（P0/P1/P2）
- 表格列：系统分类、功能分类、优先级（带颜色标签）
- 新增/编辑对话框：支持设置系统分类、功能分类、优先级
- 数据来源：dict_category表，按system/func类型分别加载
