# 一、插件面板分组展示

分组数据结构：
- 从 apis 数组中按 bizOperTraceId 分组
- 每组包含：traceId、triggerEvent、pageUrl、请求列表、ignoredCount
- 未分组请求（无 bizOperTraceId）放在"未分组"组

分组渲染逻辑：
1. 遍历 apis，按 bizOperTraceId 创建 Map
2. 按创建时间排序各组
3. 每组渲染为可折叠面板：
   - 标题栏：TraceId（截断）、触发事件图标、页面地址、请求计数、全选复选框
   - 内容区：组内请求列表，每条显示方法/URL/状态码/耗时
4. 未分组请求单独渲染

分组标题栏交互：
- 点击标题栏折叠/展开
- 全选复选框：勾选/取消勾选组内所有请求
- 组内 ignore 数量显示："3 条可疑"

分组推送：
- 推送时按分组推送，每组生成一条独立链路
- 链路名称：页面路径 + 触发事件 + 时间戳
- 未分组的 ignore 请求不推送

- 已选计数显示："已选 5 条"
- 批量操作栏：推送选中、导出选中、删除选中、标记忽略、取消忽略

前端 ChainList 多选：
- 已有 selection 列（el-table-column type="selection"）
- 已有 batch-bar 显示已选数量和批量操作按钮
- 新增：批量设置分类、批量绑定账号

# 三、链路分类管理

分类数据结构：
- 系统分类（system_category）：如"用户管理"、"订单系统"
- 功能分类（func_category）：如"登录认证"、"数据查询"
- 优先级（priority）：0=P0核心回归，1=P1常规回归，2=P2低频验证

ChainList.vue 改造：
- 筛选栏新增：系统分类下拉、功能分类下拉、优先级下拉
- 表格新增列：系统分类、功能分类、优先级
- 批量操作栏新增："批量设置分类"按钮
- 分类数据从 /api/dict/category/list 接口获取

ChainEdit.vue 改造：
- 链路基本信息区域新增：系统分类选择、功能分类选择、优先级选择
- 分类信息随链路一起保存

# 五、AI 推送后评估

评估触发时机：
- 插件推送链路到后端后，后端自动调用 AI 评估
- 评估结果存储在 ChainVersion 的 aiAnalysis 字段

评估内容（复用现有 AiServiceImpl）：
- 链路完整性检查
- 无关请求识别
- 参数依赖分析
- 重复请求检测
- 优化建议

评估结果展示：
- ChainEdit.vue 中已有 AiAnalysis 组件
- 推送成功后自动刷新 AI 分析结果
- 评估结果在链路详情页展示
