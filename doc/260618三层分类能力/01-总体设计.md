# 三层分类能力 - 总体设计

## 1. 需求概述

### 1.1 背景
当前链路推送至平台时缺少分类管理能力，无法按业务维度组织和筛选链路。需要新增三层分类体系，支持链路推送时选择分类、后台分类管理、以及按分类批量执行链路。

### 1.2 核心目标
- 插件推送弹框支持选择或填写分类（至少三层）
- 后台分类菜单支持至少三层分类的增删改查管理
- 链路列表支持按分类筛选后批量执行
- 选择父级分类时，自动包含所有子级分类下的链路

### 2.2 数据模型

#### 分类表 (test_category)
| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| category_name | VARCHAR(100) | 分类名称 |
| parent_id | BIGINT | 父分类ID，0表示顶级 |
| level | INT | 层级：1/2/3 |
| path | VARCHAR(500) | 路径：如 /1/5/12/ |
| sort_order | INT | 排序号 |
| description | VARCHAR(500) | 描述 |
| status | INT | 状态：0禁用 1启用 |
| create_time | DATETIME | 创建时间 |
| update_time | DATETIME | 更新时间 |

#### 链路表扩展字段 (test_chain)
| 字段 | 类型 | 说明 |
|------|------|------|
| category_id | BIGINT | 所属分类ID |

### 2.3 API 设计概要

| 模块 | API | 方法 | 说明 |
|------|-----|------|------|
| 分类管理 | /api/category/tree | GET | 获取分类树 |
| 分类管理 | /api/category/create | POST | 创建分类 |
| 分类管理 | /api/category/update | PUT | 更新分类 |
| 分类管理 | /api/category/delete | DELETE | 删除分类 |
| 链路推送 | /api/plugin/chain/create | POST | 推送链路（增加categoryId） |
| 链路列表 | /api/plugin/chain/list | GET | 链路列表（增加分类筛选） |
| 批量执行 | /api/execute/batchByCategory | POST | 按分类批量执行 |

## 3. 功能模块

### 3.1 插件推送弹框
- 新增分类选择器（三级联动下拉框）
- 支持快速新建分类
- 推送时携带categoryId

### 3.2 后台分类管理
- 分类树展示（树形表格）
- 新增/编辑/删除分类
- 拖拽排序
- 批量操作

### 3.3 链路列表分类筛选
- 分类筛选下拉框
- 选择父级分类时自动包含子级
- 按筛选结果批量执行
