# 提示词模板：云端上传模块

> 用途：让 Agent 复刻 WebSocket 分片上传客户端与 HTTP 兜底。

## 提示词

```
请实现一个浏览器扩展的“录制视频实时上传”客户端模块：录制过程中把视频分片通过 WebSocket
边录边传，支持断线重连与数据补发。输出可直接运行的 JavaScript 代码。

## 功能需求

### SocketClient 状态机
- 状态：connected / unconnected / reconnecting
- sentQueue：已发送、等待服务端确认的分片（带递增 id）
- willSendQueue：离线/未连接时积压的待发送分片
- retryCount：重连次数，上限 5

### 握手协议（可按你的后端调整）
- 连接 URL：wss://{your-domain}/websocket/video/open?time=<ts>
- 连接后发送：
  {"type":"init","title":"...","token":"<session>","userID":"<uid>","extra":{...}}
- 服务端回复 {type:"init", status:"1", videoURI, videoName, videoID} 后才开始录制
- 断线恢复：{"type":"recover","videoName":"...","token":"...","userID":"..."}
- 服务端回 {type:"recover", status:"1", id} 后 resendSent(id)

### 可靠发送
- send(data)：
  - connected + onLine + 无 lock：sentQueue.push({id}) + socket.send
  - 否则：willSendQueue.push(data)
- 服务端回 {type:"slice", id} 后从 sentQueue 删除
- willSendQueue 超过 150 触发错误暂停
- 重连成功后补发 sentQueue 中 id 大于服务端 id 的分片

### 其它协议
- pause：{type:"pause", videoName, reason}
- complete：{type:"complete", videoName, stopAt}；连接不可用走 HTTP
- cancel：{type:"cancel", videoName}
- 服务端 {type:"complete"} 表示可安全关闭

### 重连
- onclose → 未暂停且 needReconnect → reConnect()
- 第 0 次立即，之后 2500ms 间隔
- 5 次失败：录制中暂停并提示；否则 HTTP 检查状态

### HTTP 兜底
- POST {your-domain}/api/v1/video/complete {videoName}
- POST {your-domain}/api/v1/video/click_stop {videoID}
- POST {your-domain}/api/v1/video/annotated_flag {videoID}
- GET {your-domain}/api/v1/common/check_status

### 集成
- initVideo(options)：创建客户端，onopen 回调开始录制
- 录制 ondataavailable：本地写文件，云端 socketClient.send(blob)
- 暂停/停止/取消与录制器联动
- 错误：handleError(msg) → 暂停 + badge "!" + 提示

## 验收
- 正常录制后服务端拼出完整视频
- 断网 10 秒恢复无数据丢失
- 重连 5 次失败会暂停
- 暂停不发数据
- complete 后连接安全关闭
```

## 使用说明
- 协议字段名按你自己的后端调整
- 若后端支持，建议把确认机制升级为 seq + ack
