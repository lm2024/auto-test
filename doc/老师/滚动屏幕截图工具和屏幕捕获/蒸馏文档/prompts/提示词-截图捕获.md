# 提示词模板：截图捕获模块

> 用途：让 Agent 复刻可见区域、选区、整页滚动拼接、桌面截屏与图片上传。

## 提示词

```
请为一个 Chrome Manifest V3 扩展实现完整的截图捕获模块。输出可直接运行的代码，包括后台控制器、
content script、独立桌面截屏页面。

## 功能需求

### 1. Visible Part 可见区域
- content script 对当前视口截图
- 支持 PNG/JPEG 两种格式
- 支持延迟（delay_sec 秒）

### 2. Selected Area 选区截图
- 注入遮罩 UI（z-index 高于 2147483600）
- 支持鼠标拖拽与触屏（touchstart/move/end）
- 显示尺寸提示与 Cancel / Capture / Copy 按钮
- 选区坐标按 devicePixelRatio 换算
- 支持调整选区大小（8 个方向手柄，可选）

### 3. Full Page 整页滚动截图
- 初始化：计算 scrollHeight、scrollBarWidth、正文区域 contentClip、背景采样 bgRegions
- 循环：截当前视口 → 自动滚动 → 回传后台拼接
- 背景填充：对左右两侧 bgRegions 采样主色，用像素频次统计得到主色，填充拼接空隙
- 处理移动端 visualViewport.scale > 1 的缩放
- 最大高度 100000px 防内存溢出
- 无限滚动页面滚动次数 >= 9 提示手动停止
- 用户点击 Stop 立即终止

### 4. Desktop 桌面截屏
- 独立页面 capture-desktop.html
- chrome.desktopCapture.chooseDesktopMedia(["screen","window"]) 选择来源
- getUserMedia({video:{mandatory:{chromeMediaSource:"desktop", chromeMediaSourceId}}})
- 播放 300ms 后 canvas 定格 → dataURL
- 支持延迟截图（badge 倒计时）
- 用户取消选择时关闭窗口
- 错误分类：Mac 系统权限 / Windows 音频源冲突，跳转错误引导页

### 5. 图片保存/上传
- 本地：保存文件或打开标注页
- 云端：创建图片 ID → 分块上传 → 完成接口 → 失败指数退避重试
- 离线：自动降级本地

## 消息协议
- popup → bg：{action:"visible"|"selected"|"entire"|"delay"|"desktop"|"annotate"}
- bg → content：{action:"init_entire_capture"}、{action:"stop-entire-capture"} 等
- content → bg：{action:"scroll_next_done", dataURL, ...}

## 验收
- 长页面拼接无错位、无缝隙
- devicePixelRatio=2 屏幕选区准确
- 桌面截图可取消
- 上传失败自动重试
```

## 使用说明
- 上传部分可用你自己的服务端接口替换
- 如不需要云端，删掉第 5 节的云端分支即可
