# 提示词模板：标注系统模块

> 用途：让 Agent 复刻录制控制栏 + 鼠标/点击高亮 + 图片标注编辑器。

## 提示词

```
请实现一个 Chrome 扩展的标注系统：录制时的页面控制栏与绘图工具栏，以及截图后的图片标注编辑器。
输出可直接运行的代码。

## 功能需求

### 1. 录制控制栏（content script 注入）
- 工具栏状态：
{
  mouseMode: "mouse",       // mouse | annotation
  currentMouse: "default",  // 鼠标效果
  drawMode: "freeline",     // 画笔模式
  currentColor: "red",
  isCollapse: false,
  isPaused: false
}
- 工具：Pause、Resume、Stop、Discard、Collapse/Expand
- 鼠标效果：Default、Highlight Mouse（跟随光标高亮）、Highlight Click（点击涟漪）
- 画笔：Free line、Pen、Arrow、Rectangle、Ellipse、Text、Callout、Emoji、Image、Blur、Spotlight、Step
- Undo、Remove single、Remove all、Clear

### 2. 注入与移除
- desktop 模式：chrome.tabs.query({}) 广播到所有标签页
- tab/custom：只注入录制标签页
- 图标资源加入 web_accessible_resources
- 移除时发 remove-toolbar 并清理后台状态

### 3. 暂停联动
- 工具栏暂停/恢复与录制器状态同步
- 页面浮层显示暂停态

### 4. 图片标注编辑器
- 打开页面（annotate.html），接收图片 dataURL/URL
- 图层模型：背景图 canvas + 标注层 + SVG doodle 数组
- doodle：{type, points, pen_width, pen_color, ...}
- 工具：画笔、直线、箭头、矩形、椭圆、文字、列表、模糊、水印、裁切
- 命令栈实现 Undo/Redo（可撤销到任意一步）
- 选中 doodle 后显示编辑手柄（移动/旋转/缩放）
- 触屏支持：gesturestart/gesturechange/gestureend
- 保存：PNG/JPEG 导出；可选上传云端
- 支持 Retina 50% 缩放导出

## 验收
- 工具栏在所有目标页面正常显示
- 鼠标/点击高亮与录制画面同步
- undo/redo 正确
- 暂停时工具栏状态同步
- 移除工具栏无残留 DOM
- 编辑器标注导出图片正确
```

## 使用说明
- 可要求直接集成 Diigo annotator 库，或从零实现简化版
- 云端上传部分可裁剪
