# 提示词模板：事件用例录制器

> 用途：让 Agent 实现类似 Chrome DevTools Recorder 的“Untitled Test Case”用户操作录制与回放。

## 提示词

```
请为一个 Chrome 扩展实现“用户操作用例录制器”，功能对标 Chrome DevTools Recorder：
录制用户操作 → 生成“Untitled Test Case” → 步骤可识别事件类型、可排序、可回放、有日志面板。

## 功能需求

### 1. 录制
- content script 在捕获阶段监听 DOM 事件：
  - click / dblclick
  - input / change（记录 before 与 after 值）
  - keydown / keyup（key、code、modifiers）
  - scroll / wheel（100ms 节流）
  - focus / blur、submit
- 为每个目标元素生成稳定选择器：
  1. #id（页面内唯一）
  2. [data-testid] / [data-qa] / [name] / [aria-label]
  3. 语义标签（button、a、input[type=submit]）
  4. CSS 路径 body > div:nth-child(2) > button
  5. 文本回退
- 同时记录 tagName、text、href、value、xPath
- iframe：记录 framePath（逐级 frame 索引）
- Shadow DOM：记录 shadowHostPath + 内部路径
- 安全：input[type=password] 只记录 masked:true；敏感字段跳过

### 2. 用例模型
{
  "id": "case_xxx", "name": "Untitled Test Case", "url": "...",
  "steps": [{ "id", "order", "type", "selector", "framePath", "x", "y", "value", "key", "timestamp" }]
}
- 默认名 “Untitled Test Case”，可重命名
- 存 IndexedDB 或 chrome.storage.local

### 3. 管理面板
- 步骤列表：类型图标 + 选择器/参数 + 时间
- 拖拽或按钮调整顺序
- 删除 / 复制步骤
- 插入 wait / assertion 步骤（assertText、assertVisible）
- 导出 JSON、导入 JSON

### 4. 回放引擎
- 逐步骤执行：
  - 定位元素（querySelector + MutationObserver 等待，默认 10s 超时）
  - click：el.dispatchEvent(new MouseEvent("click", {bubbles:true, clientX, clientY}))
  - input：nativeInputValueSetter + dispatchEvent(input/change)，兼容 React/Vue
  - key：KeyboardEvent(key, code, keyCode, modifiers)
  - scroll：el.scrollTo / window.scrollTo
  - navigate：location.href 或 chrome.tabs.update
  - wait：setTimeout
- 失败策略：重试 2 次 → 跳过 → 暂停询问
- 跨页面：监听 chrome.tabs.onUpdated 重新注入 content script

### 5. 日志面板
- 每步：开始时间、耗时、状态（success/failed/skipped）、错误
- 实时追加，虚拟滚动
- 回放结束输出摘要（通过率、总耗时、失败步骤）
- 同时 console.log 结构化输出

## 验收
- 普通网页录制回放结果一致
- React 输入框回放值正确
- 动态元素回放成功
- 步骤可排序、删除、重命名
- iframe / Shadow DOM 可录制回放
- 密码不明文存储
```

## 使用说明
- 若只想要录制与展示（不回放），删除第 4、5 节
- 若作为独立网页工具（非扩展），把 content script 换成普通网页脚本
