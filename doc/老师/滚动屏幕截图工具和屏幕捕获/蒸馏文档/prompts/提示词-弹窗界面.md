# 提示词模板：弹窗界面模块

> 用途：让 Agent 复刻一个截图/录制扩展的弹窗 UI 与交互逻辑。

## 提示词

```
请基于以下需求，为一个 Chrome Manifest V3 扩展实现完整的弹窗界面模块。输出可直接运行的代码。

## 目标
仿照 AwesomeScreenshot 的弹窗：点击工具栏图标弹出面板，包含“截图”和“录制”两个 Tab，
支持截图入口、录制设置、设备权限检查、录制中实时控制。

## 功能需求

### 截图 Tab
- 按钮：Visible Part、Selected Area、Full Page、Desktop、Annotate Local Image
- 每个按钮显示快捷键提示（Ctrl+Shift+数字）
- 点击后通过 chrome.runtime.sendMessage 通知后台
- 不可注入页面（chrome:// 等）按钮置灰

### 录制 Tab
- 录制类型：Desktop / This Tab / Custom Region / Camera Only
- 选项：
  - Microphone 开关 + 设备下拉
  - Embed Camera 开关 + 设备下拉
  - Tab Sound（仅 tab/custom）
  - Control Bar 开关
  - Max Resolution：720 / 1080 / 4K
  - Save to：Cloud / Local
  - Countdown：0-60 秒
  - Auto-stop：时/分/秒
- 开始录制流程：
  1. 校验登录态与额度（可选）
  2. 组装 recordOptions
  3. Desktop 打开 popup 窗口 /record.html；Camera 打开标签页
  4. 页面加载完成后发 startRecord 消息

### 录制中视图
- 计时显示（100ms 刷新）
- 暂停 / 继续 / 停止 / 丢弃
- 摄像头、麦克风、标注工具栏、定时开关
- 定时可编辑（读取后台 timerHour/Min/Sec）

### 技术约束
- 配置存 chrome.storage.local.options，不直接读 localStorage
- 用 chrome.i18n.getMessage 做文案
- 设备枚举用 navigator.mediaDevices.enumerateDevices + permissions.query
- 录制状态从 chrome.storage.local 读取，录制窗口对象通过 chrome.extension.getViews 获取
- 支持暗色模式

## 验收
- 双 Tab 能记忆上次选择
- 关闭弹窗后录制继续
- 无权限时引导到授权页
- 代码结构清晰，注释精简
```

## 使用说明
- 删除“登录态与额度”需求可生成纯本地版
- 可追加要求：React 实现或原生 JS 实现
