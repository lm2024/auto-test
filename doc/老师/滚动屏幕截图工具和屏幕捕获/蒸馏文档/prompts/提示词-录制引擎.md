# 提示词模板：录制引擎模块

> 用途：让 Agent 复刻桌面/标签页/区域/摄像头四种录制能力。

## 提示词

```
请为一个 Chrome Manifest V3 扩展实现完整的录制引擎模块。输出可直接运行的代码。

## 功能需求

### 四种录制模式
1. Desktop：chrome.desktopCapture.chooseDesktopMedia(["screen","audio","window"])
   + getUserMedia(chromeMediaSource:"desktop")；录制控制窗口用 popup 窗口 /record.html
2. This Tab：chrome.tabCapture.capture({audio, video, videoConstraints})
   ；后台播放 tabSoundAudioPlayer 消费音轨
3. Custom Region：tabCapture + 用户框选区域 + ImageCapture.grabFrame() + canvas 34ms 重绘
   + canvas.captureStream() 合成输出流
4. Camera Only：getUserMedia({video, audio})，支持 Picture-in-Picture

### 音频处理
- 麦克风与系统声音混音：AudioContext + createGainNode(gain=0) + createMediaStreamDestination
- 无麦克风时保证输出流仍有音频轨
- 麦克风热插拔：监听 track.onended，自动重连 default 设备
- navigator.mediaDevices.ondevicechange 监听设备恢复

### 录制生命周期
- beginRecord(options) → 取流 → preparing 状态 → 倒计时（badge 显示秒数）→ gotStream → recording
- RecordRTC 或原生 MediaRecorder：
  - type video，mimeType video/webm; codecs=vp8
  - timeSlice：本地 3000ms，云端 500ms
  - ondataavailable 分片回调
- 暂停/继续：暂停时暂停录制器 + 记录 pausedTime
- 自动停止：时/分/秒定时，到时自动 stopStream
- 停止：recorder.stopRecording(cb) → 本地保存 / 云端 complete → setDefaults 清理
- 丢弃：discard=true 时删除本地记录或 cancel 云端

### 时长限制
- 免费用户 5 分钟自动停止（可配置开关）
- 2 小时提醒

### 消息协议
- popup → bg：{action:"startRecord", recordOptions}、{action:"stopStream"}
- bg → content：insertRecordDiv、prepareCustom、startCountDown、pause、resume、removeRecordDiv
- bg → popup：updateRecordUI

## 验收
- 四种模式都能录出可播放 webm
- 混音无回授
- 关闭弹窗后录制继续
- 标签页关闭自动停止
- 暂停不计时长
- 错误时（权限拒绝/音频冲突）跳转引导页
```

## 使用说明
- 可要求使用 RecordRTC 库或纯 MediaRecorder
- 云端分支可替换为你自己的上传通道
