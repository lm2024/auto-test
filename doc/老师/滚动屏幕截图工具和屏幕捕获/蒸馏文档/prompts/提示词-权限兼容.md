# 提示词模板：权限兼容与设置

> 用途：让 Agent 复刻扩展权限体系、页面限制、多浏览器兼容、快捷键、上下文菜单与设置页。

## 提示词

```
请为一个 Chrome Manifest V3 截图/录制扩展实现权限体系、浏览器兼容、快捷键、上下文菜单与设置页。
输出可直接运行的 manifest 与代码。

## 功能需求

### 1. Manifest 权限
{
  "permissions": ["storage", "unlimitedStorage", "desktopCapture", "activeTab", "scripting"],
  "optional_permissions": ["downloads", "notifications"],
  "host_permissions": ["<all_urls>"]
}
- 说明每个权限的必要性
- downloads / notifications 用 chrome.permissions.request 按需申请

### 2. 页面限制
- 定义 isNotAcceptedTab(url)：
  - chrome://*、edge://*、chrome-extension://*
  - chrome.google.com/webstore、ntp.msn.cn/edge/ntp、about:blank
- 弹窗根据当前 URL：
  - 非 http/https/file/ftp 禁用内容相关按钮
  - 页面未 complete 禁用选区
  - file:// 需 chrome.extension.isAllowedFileSchemeAccess()
- https 页面禁用选区截图（可选安全策略）

### 3. 浏览器兼容
- UA 检测 Chrome / Edge(Edg) / Firefox / Opera / Safari、Windows/Mac/Linux
- MediaRecorder 支持检测（Chrome 49+）
- 老浏览器回退：canvas + WebP 合成 webm
- 客户端名区分 Edge / Chrome

### 4. 快捷键
- manifest.commands：
  - start-or-stop-recording
  - pause-or-resume-recording
- chrome.commands.onCommand 处理

### 5. 上下文菜单
- Record Screen / Record Tab（录制前）
- Stop Recording（录制中）
- chrome.contextMenus.update 切换可见性

### 6. 设置页
- 默认值集中管理：
  - 图片格式 png、延迟 3s、倒计时 3s、分辨率 720
  - 快捷键 visible/selected/entire
  - 保存位置 cloud/local
  - 暗色模式、自动保存路径、提醒开关
- 所有设置存 chrome.storage.local.options
- 版本迁移：安装/升级时用版本号比较补默认值

### 7. 安装与卸载
- onInstalled：写默认值；安装时可选打开引导页
- setUninstallURL 卸载调查（可选）

## 验收
- chrome:// 页面不报错、按钮禁用
- file:// 权限开关生效
- 未授予 downloads 时下载仍可用
- Edge 下扩展正常
- 快捷键可用
- 升级后默认值正确补齐
```

## 使用说明
- 页面黑名单可按个人需要增删
- 引导页、卸载调查可裁剪
