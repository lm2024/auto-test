# 浏览器插件打包实操步骤

本文档以 `plugin-test` 插件为例，介绍如何将未打包的插件目录打包成 `.crx` 文件或发布到 Chrome 应用商店。

---

## 一、开发模式加载插件（调试用）

在打包前，先用开发模式加载插件进行调试：

1. 打开 Chrome 浏览器，地址栏输入 `chrome://extensions/` 回车
2. 右上角打开 **「开发者模式」** 开关
3. 点击 **「加载已解压的扩展程序」** 按钮
4. 选择 `plugin-test` 文件夹
5. 插件加载成功，出现在列表中

> 此模式仅用于本地调试，不能分享给他人。

---

## 二、打包成 .crx 文件

### 方法一：通过 Chrome 浏览器打包（推荐新手）

1. 打开 `chrome://extensions/` 页面
2. 确保 **「开发者模式」** 已开启
3. 点击 **「打包扩展程序」** 按钮
4. 在弹窗中：
   - **扩展程序根目录**：选择 `plugin-test` 文件夹
   - **私钥文件**：首次打包留空（自动生成），后续打包选择已有的 `.pem` 文件
5. 点击 **「打包扩展程序」**
6. 打包完成后，在 `plugin-test` 的**父目录**会生成两个文件：
   - `plugin-test.crx` — 插件安装包
   - `plugin-test.pem` — 私钥文件（**务必妥善保管，丢失后无法更新插件**）

### 方法二：使用命令行工具

```bash
# 需要安装 Chrome 浏览器（Chromium）

# Windows
chrome --pack-extension="C:\path\to\plugin-test" --pack-extension-key="C:\path\to\key.pem"

# macOS
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --pack-extension="/path/to/plugin-test" --pack-extension-key="/path/to/key.pem"

# Linux
google-chrome --pack-extension="/path/to/plugin-test" --pack-extension-key="/path/to/key.pem"
```

## 三、安装 .crx 插件

其他用户安装打包好的插件：

1. 将 `.crx` 文件发送给目标用户
2. 用户打开 `chrome://extensions/` 页面
3. 将 `.crx` 文件直接**拖拽**到浏览器扩展页面
4. 在弹窗中点击 **「添加扩展程序」** 确认安装

> 注意：Chrome 87+ 版本可能限制安装未上架的 `.crx`，需开启开发者模式或使用「拖拽安装」方式。

---

## 四、发布到 Chrome 应用商店（可选）

如需公开发布：

1. 注册 Chrome 开发者账号：https://chrome.google.com/webstore/devconsole
2. 编辑 `manifest.json`，补充必要字段：

```json
{
  "name": "捉接口 TraceFlow",
  "description": "录制页面所有网络请求，支持链路回放与版本对比，一键推送至自动化测试平台",
  "version": "1.1.0",
  "icons": {
    "16": "icons/icon16.png",
    "48": "icons/icon48.png",
    "128": "icons/icon128.png"
  }
}
```

3. 准备截图（至少 1 张 1280×800 的截图）
4. 登录开发者后台，点击 **「新增商品」**
5. 上传 `.crx` 文件或 ZIP 包，填写商品信息
6. 提交审核，等待 Google 审核通过后上架

---

## 五、打包注意事项

| 项目 | 说明 |
|------|------|
| manifest_version | 当前使用 V3，Chrome 2023 年起强制要求 V3 |
| 图标尺寸 | 必须包含 16×16、48×48、128×128 三种 |
| 权限说明 | `permissions` 中的权限需在商店审核时说明用途 |
| 私钥安全 | `.pem` 文件是更新插件的凭证，泄露会导致插件被恶意覆盖 |
| 版本号 | 每次发布必须递增 `version` 字段 |
| 文件大小 | 商店限制单个插件包不超过 128MB |

## 六、常见问题

**Q: 打包报错 "Extension directory does not contain a valid manifest"**
A: 确认 `manifest.json` 在选择的目录根目录下，且格式合法（JSON 无语法错误）。

**Q: 打包后安装提示 "该扩展程序未在 Chrome 网上应用店中列明"**
A: 开启开发者模式后即可安装，或通过拖拽方式安装。

**Q: 更新插件后旧版本数据会丢失吗？**
A: 使用相同的私钥打包并递增版本号，`chrome.storage` 中的数据会保留。

**Q: 如何分享给团队成员？**
A: 将 `.crx` 文件发送给对方，对方拖拽安装即可；或使用企业内部插件托管服务。
