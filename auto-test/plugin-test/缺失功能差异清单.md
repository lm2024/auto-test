# 捉接口 TraceFlow 插件 — 缺失业务功能差异清单（对照 Katalon Recorder）

> 目的：对照"老师"（Katalon Recorder 蒸馏文档）的能力体系，列出本插件 `plugin-test` 当前**缺失**或**仅部分具备**的业务功能，方便后续决定是否继续增加。
> 蒸馏文档路径：`doc/老师/KatalonRecorder/蒸馏文档/tech/`（TECH-03 回放引擎 / TECH-06 兼容与 Polyfill / TECH-07 入口与弹框 / TECH-21 API 抓包与文档生成）。

## 一、回放引擎（对照 TECH-03）— 差距最大

老师的回放是面板内递归 Promise 状态机，命令体系极其完整；本插件只有最基础的 UI 操作线性回放。

| 能力 | 老师 | 本插件 | 说明 |
|---|---|---|---|
| 变量系统 `storedVars` | ✅ 完整（环境变量/随机数/日期/算术） | ❌ 缺失 | 回放时可引用与赋值，宏可参数化 |
| 流程控制 | ✅ `if/else`、`times`、`while`、`gotoLabel/label` | ❌ 缺失 | 本插件只有顺序执行 |
| 等待命令 | ✅ `waitForElementVisible/NotVisible`、`waitForText`、`waitForPageToLoad`、`pause`、`echo` | ⚠️ 部分 | 有 `waitForElement` + 固定 `macroActionDelay`，但无显式可见性/文本/页面加载等待命令 |
| 断言命令 | ✅ `assert/verify/storeText/storeValue/assertTitle` | ❌ 缺失 | 本插件回放**只执行不校验**，无结果断言 |
| 每条命令前内置等待 | ✅ 强制插 5 个内部等待命令 | ❌ 缺失 | 本插件靠粗粒度 `macroActionDelay` |
| 失败处理 | ✅ `continue/break`、失败截图、断点 | ⚠️ 部分 | 本插件记录失败状态，但无重试/断点/截图 |
| 跨页面跳转回放 | ✅ 完整 | ✅ **本次已补全** | 用 storage 保存断点 index，新页面加载自动续跑 |
| 步骤高亮 / 慢动作 | ✅ | ❌ 缺失 | |
| 数据驱动（csv / 数据源参数化） | ✅ | ❌ 缺失 | |

## 二、录制与命令类别（对照老师命令体系）

老师录制产出标准命令：`open / click / type / select / check / mouseOver / dragAndDrop / doubleClick / rightClick / sendKeys / submit / echo / comment / pause`。

本插件当前录制类型：`click / input / select / check / submit / keypress / navigate`。

**缺失命令类型**：`doubleClick`、`rightClick`、`mouseOver`、`dragAndDrop`、`sendKeys`（组合键）、`assert*`、`store*`、`echo`、`comment`、`pause`。

## 七、建议优先级（供你选择是否继续增加）

**P0（强烈建议，性价比高）**
1. 回放变量系统 `storedVars`（让宏可参数化，复用价值陡增）
2. 断言命令（`assert*` / `verify*`）—— 否则回放只是"点一遍"，没有校验价值
3. 导出 Postman 集合 / JUnit（平台 CI 集成刚需）

**P1（体验提升）**
4. 流程控制（`if` / `loop` / `label`）
5. 缺失命令类型（`doubleClick` / `rightClick` / `dragAndDrop` / `sendKeys`）
6. 步骤高亮 + 慢动作 + 断点调试
7. 数据驱动（csv 参数化）

**P2（工程化）**
8. webextension-polyfill + Firefox 兼容
9. offscreen 真正落地解密沙箱
10. 多窗口录制态同步防串
