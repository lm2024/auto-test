================================================================================
  AutoTest 前端 Nginx 包 (ARM64 / aarch64 Linux)
================================================================================

本目录是一个「开箱即用」的 Nginx，专为纯内网 ARM64 Linux 服务器打包：
  - sbin/nginx   : Nginx 1.26.2 静态链接二进制（任意 ARM64 Linux 发行版可直接运行）
  - conf/nginx.conf : 已配好「前端静态服务 + 后端 /api 代理 + /ws WebSocket」
  - conf/mime.types : MIME 类型表
  - start.sh / stop.sh / restart.sh : 启动/停止/重载脚本
  - logs/        : 运行日志

================================================================================
一、部署前准备
================================================================================

1. 把整个 frontend/ 目录（含本 nginx/、node_modules/、dist/）拷贝到内网服务器
2. 确保已生成前端产物 dist/：
     在能联网的机器上：cd frontend && npm install && npm run build
     （dist/ 已生成后，连同本目录一起拷进内网即可）
3. 确保后端 Spring Boot 已在 127.0.0.1:8080（或你改的地址）运行

================================================================================
二、需要改的配置（只有两处，都在 conf/nginx.conf）
================================================================================

【修改这里 1】监听端口 listen
    默认 80。若不用 root 运行或 80 被占，改 listen 8081; 访问 http://IP:8081

【修改这里 2】后端地址 proxy_pass
    默认 http://127.0.0.1:8080（后端同机）。
    后端在别的机器时，改成 http://后端内网IP:8080

其余一律【不用修改】。

================================================================================
三、在 ARM64 Linux 上运行
================================================================================

  cd /路径/frontend/nginx
  chmod +x start.sh stop.sh restart.sh sbin/nginx   # 首次执行一次

  ./start.sh        # 启动
  ./stop.sh         # 停止
  ./restart.sh      # 改完 nginx.conf 后重载

启动后浏览器访问：http://服务器IP    （或你设的端口）

================================================================================
四、排错
================================================================================

- 启动报权限不足：listen 80 需要 root，用 sudo ./start.sh 或改高端口
- 页面打不开：看 logs/error.log；确认 dist/ 已生成、后端已启动
- 改配置不生效：./restart.sh 重载
- 端口被防火墙挡：开放对应端口（如 firewall-cmd --add-port=80/tcp）
================================================================================
